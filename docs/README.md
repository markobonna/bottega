# Bottega docs — video-team index

Start here, in this order:

1. `Project-Brief.md` — what Bottega is, the stack, the rules. One page.
2. `demo_video.md` — the judged 3-minute video, beat by beat with exact
   lines. This is the shoot script.
3. `x_hype_video.md` — the under-60s X cut (Maria-and-Cole-led, no
   founder on camera) plus the alt vendor-film concept.
4. `project_steps.md` — what is actually on screen at every step of
   every trade. Read from the code; the ground truth for captions.
5. `maria-cole-projects.md` — what the two guest worlds contain
   (workshops, projects, final states).
6. `Bottega Models and Providers.md` — which Meta model does what,
   what happens without a key, and what we can truthfully claim.
7. `sample-runs.md` — captured outputs (tests, build, seed) so the
   project evaluates with or without a live model key.
8. `project-submission.md` — the hackathon form answers.

Also in this folder: `design/` (the original mockups — reference only,
the app has moved past them) and `public` (an extensionless JPEG: a
photorealistic empty-workshop still for reference).
