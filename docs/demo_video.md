## E — Build live: software for the stall the sign hangs on. (1:10–2:40)

DO: go to create a new project

> "Now for software — an app tracking my food truck sales."

DO: describe it — 

> "an app tracking my food truck sales. I call in orders from the truck, customers' orders get logged." 

DO: State Software

DO: Sketch step — pick mobile (the only question), the countdown
holds while Spark designs the app — real screens, real styling,
not boxes. SAY:

> "One question first — mobile or desktop? Then Muse Spark designs the app."

DO: advance to Prototype — tap through the working app live in the
board (add a sale, watch it save). One change-bar sentence
("make it plum") → preview names the files → Accept → it updates.
SAY:

> "Prototype: not a mockup — the app, running. And it keeps
> improving — one sentence, preview, accept."

DO (one flowing beat): Download dialog — file readout (names + KB,
counted) → Download code (.zip): the download itself stamps it
done → green Downloaded card, stamped board → unzip on camera,
open index.html in a browser, tap through. SAY:

> "Download — four files, vanilla JS, zero dependencies,
> double-click and it runs. First pass: download it to keep adding
> features, or hand it to us to develop further. Downloaded — and
> here's the code outside Bottega, running on its own. Atoms and
> bits, one talk bar — take it, or hand it to us."

IF-FAILS: design stalls → "The model's thinking — the second live
wait." (Cut, come back when the Blueprint lands.)
File won't open on camera → skip it: "and the file's yours — it
runs anywhere."
